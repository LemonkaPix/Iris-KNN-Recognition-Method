# KNN Classification on the Iris Dataset

## Project Description

This project implements the **Nearest Neighbors** algorithm to classify data from the **Iris dataset**. KNN is a fundamental machine learning algorithm based on the similarity to the nearest neighbors. The Iris dataset contains information about three species of iris flowers: *setosa*, *versicolor*, and *virginica*.

The goal of the project is to use dataset to classify iris species based on their features (sepal length and width, petal length and width) and evaluate its classification performance.

## Dataset

The Iris dataset is publicly available and contains 150 samples across three classes:

1. **Iris-setosa** 
2. **Iris-versicolor**
3. **Iris-virginica**

Each sample is described by four features:
- Sepal length,
- Sepal width,
- Petal length,
- Petal width.
